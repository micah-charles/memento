# `tests/`

`Memento.Core.Tests` contains deterministic storage, audio-recovery, provider-boundary, language-validation, clarification, provenance, entity, review, export/backup, and health tests. Physical microphone, live provider, native-window, OS-authentication, and real-user acceptance tests remain target-machine work described in [ROADMAP.md](../docs/ROADMAP.md). The M04 synthetic corpus can also be regenerated through the [language-validation CLI](../tools/Memento.LanguageValidation/).
