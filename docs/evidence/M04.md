# M04 evidence — Cantonese and mixed-language validation framework

**Date:** 2026-09-13  
**Status:** PARTIAL/BLOCKED pending real-provider corpus

## Scope

Measure language behaviour instead of assuming that a generic multilingual label implies Hong Kong Cantonese quality.

## Implementation

`LanguageValidationHarness` evaluates synthetic cases across Cantonese, Mandarin, code-switching, names, places, dates, numbers, hesitations, repetitions, incomplete sentences, uncertainty, and English product names. `LanguageValidationCorpus.SyntheticCases` now provides one non-sensitive case for every required category, and the coverage test runs the complete corpus through the report path. Code-switch cases can declare required language segments so a missing Cantonese, Mandarin, or English segment is measured separately from overall transcript similarity. The report includes entity accuracy, uncertainty preservation, latency, a disposition, and a machine-readable correction-required flag/count.

## Verification

`dotnet test tests/Memento.Core.Tests/Memento.Core.Tests.csproj --configuration Release` passed **18/18** at the M04 checkpoint; the later complete synthetic-corpus coverage test brings the current suite to **185/185**. Fixtures are synthetic and deliberately contain no family recordings, private transcripts, or provider credentials.

The reproducible report command is:

```powershell
dotnet run --project tools/Memento.LanguageValidation/Memento.LanguageValidation.csproj --configuration Release -- --output artifacts/language-validation/synthetic-report.json
```

It evaluates the complete synthetic corpus and writes the case-level JSON report. The report is wiring evidence only; it does not establish real-provider Cantonese quality.

## Gate decision

**PARTIAL/BLOCKED.** The harness is reproducible and ready for a consented corpus, but no real provider or Hong Kong Cantonese sample was run. No language-quality PASS is claimed.
