# M02 evidence — reliable local audio capture

**Date:** 2026-09-13  
**Status:** PARTIAL/BLOCKED pending physical microphone and native-window verification

## Scope

Local-only capture that preserves primary audio evidence independently of any future cloud provider.

## Implementation

- `PcmWaveWriter` writes PCM WAV to a date-organized `raw/audio` directory using a `.capture.tmp` suffix.
- Session and Source identifiers are rejected when they contain path separators or invalid file-name characters, so archive media cannot escape its date-organized root through a malformed ID.
- Each append validates complete sample frames and flushes to disk. Finalization closes, validates, hashes, and atomically renames the temporary file before registering `SourceMetadata`.
- Each append also refreshes the temporary WAV data-length field; `AudioRecoveryScanner` finds unfinished captures, recovers complete PCM frames left behind by a stale header after interruption, and reports valid or corrupt files without deleting them.
- `AudioCaptureController` enforces explicit local-capture consent and records session/source linkage.
- `WaveInAudioInput` is the Windows NAudio adapter; the core contract remains provider-neutral.
- The WinUI shell exposes consent-gated start/stop controls and local recording status.
- The shell closes the active session when a capture error callback fires, so a failed device/write path cannot leave an open session while the recoverable temporary file remains.
- A failed new capture also clears the shell's active session/Source pairing, preventing an old finalized recording from being offered under the failed session identity.

Synchronous input-start failure leaves the controller in `Failed` instead of re-entering `Capturing`; input disposal, finalization, or Source-registration failures also raise the same recovery event.
