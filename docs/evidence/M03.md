# M03 evidence — provider boundary and bounded cloud path

**Date:** 2026-09-13  
**Status:** PARTIAL/BLOCKED pending credentialed live verification

## Scope

Keep local audio authoritative while allowing a future live voice provider to process only explicitly permitted content.

## Implementation

- `ConversationOrchestrator` accepts a finalized local audio path, privacy mode, and cloud consent. It rejects `LOCAL_CAPTURE_ONLY`, missing consent, or missing local evidence before provider transmission.
- `IConversationProvider`, `ITranscriptionProvider`, and `IReasoningProvider` keep vendor-specific transport and model objects outside the domain/archive.
- `provider_interactions` stores provider, capability, model, model snapshot, request ID, timestamps, coarse usage, success, and error metadata.
- `DeterministicConversationProvider` supports offline contract tests and is explicitly labelled as a test provider.
- `OpenAiTranscriptionProvider` provides an optional completed-audio HTTP adapter. It requires an injected credential, sends only a finalized local WAV, and does not persist credentials or raw error bodies. A realtime spoken-response adapter and secure client-token broker remain future work.
- `OpenAiResponsesProvider` and `BoundedVoiceConversationService` provide a turn-based fallback: a finalized local WAV and explicit Source ID are transcribed before a text response request, the initial transcript revision is persisted, and `store=false` is sent for Responses calls. Optional `OpenAiSpeechOutputProvider` produces derived speech bytes; `DerivedAudioStore` can atomically persist and hash them in the separate `derived_speech_assets` table, while playback and Realtime transport remain future work.
- Successful and failed speech-output calls are recorded in `provider_interactions` with capability `speech_output`; generated audio is kept outside participant Source/Evidence records.
- `WindowsCredentialProvider` reads an optional API key from Windows Credential Manager through an injected target name; credentials are never committed or written to the SQLite archive.
