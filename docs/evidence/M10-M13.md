## M10 — current-information tools

`ISearchProvider` and `CurrentInformationService` return time-bound, URL-bearing, explicitly untrusted external information. `OpenAiWebSearchProvider` sends the Responses web-search tool with an explicit HTTPS domain allowlist and `store=false`, then discards citations outside that allowlist. The service has no path to mutate Evidence, Claims, or vocabulary.

The adapter follows the Responses API web-search tool and `web_search_call.action.sources` inclusion described in the [official Responses API reference](https://developers.openai.com/api/reference/cli/resources/responses/methods/create). The reference establishes request/response shape, not MEMENTO account access, freshness, or source quality.

## M11 — Family Admin

`IAdminAuthorizer` gates candidate listing and review annotations. `FamilyAdminReviewService` records the actor and annotation type, and only explicit family support/admin rejection changes candidate status. `WindowsAdministratorAuthorizer` binds authorization to the current Windows account and Administrators role; the fixed authorizer in tests remains a fixture. The WinUI shell exposes a candidate review dialog that shows each linked Evidence item, relationship, participant certainty, and speaker-confirmation state. An administrator can also play the latest finalized PCM WAV Source after its archived length, SHA-256, and WAV structure are verified; physical output-device verification remains pending.

Export, encrypted backup, and restore-verification controls use the same authorization boundary and record a minimal archive operation audit without storing paths or archive content.

## M12 — export and backup

`ArchiveExporter` writes table JSONL, an SQLite snapshot, optional source and derived-speech media, and a SHA-256 manifest. `ArchiveBackupProtector` encrypts and restores snapshots or complete export bundles with PBKDF2-derived AES-GCM keys, safe zip extraction, duplicate-entry rejection, and streaming manifest hash verification; wrong/corrupt passwords and unsafe archive paths fail.

## M13 — reliability/security foundations

`ArchiveHealthCheck` surfaces SQLite integrity, schema version, unfinished audio, due jobs, missing/tampered finalized source or derived speech assets, and parity between canonical transcript/Evidence/Claim rows and the rebuildable search index. The dependency vulnerability scan reports no vulnerable packages, and repository scans found no credentials or private media.

`ArchiveDeletionService` requires the Family Admin authorizer, removes a Source's dependent revisions, evidence, episodes, jobs, derived assets, and orphan entities, attempts to remove media, and records only a minimal authenticated deletion tombstone. It removes a Memory Claim only when no Evidence links remain; claims supported by another Source retain their remaining links, annotations, and search entry.

Deletion now also removes session-level provider metadata and derived speech when the deleted Source is the only session-level Source; when that scope is ambiguous, the records remain with an explicit finding rather than being deleted accidentally.

`ArchiveWithdrawalService` requires the same Family Admin boundary and records an attributed withdrawal annotation while retaining the historical Source and media. Pending/retryable jobs are terminally blocked, queued/future transcription and extraction re-check the withdrawn status, local lexical search omits withdrawn Source-linked records and claims, and ordinary exports produce a sanitized snapshot; an explicit `includeWithdrawn` export is available for controlled administrative handling.
