`ArchiveExporter` writes table JSONL, an SQLite snapshot, optional media, and a SHA-256 manifest. `ArchiveBackupProtector` encrypts and restores snapshots with PBKDF2-derived AES-GCM keys; wrong/corrupt passwords fail decryption.
