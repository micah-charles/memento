## M10 — current-information tools

`ISearchProvider` and `CurrentInformationService` return time-bound, URL-bearing, explicitly untrusted external information. The service boundary overwrites provider-supplied query/provider/trust metadata with the caller query, the configured provider identity, and `IsUntrustedExternalInformation=true`, so a provider cannot label output as trusted or spoof its audit identity. `OpenAiWebSearchProvider` sends the Responses web-search tool with an explicit HTTPS domain allowlist and `store=false`, then discards citations outside that allowlist. The WinUI result area shows the local retrieval time, provider, source links, and the external-data notice, and clears that result when cloud consent is withdrawn, a local-only mode is selected, or a new recording session starts; the service has no path to mutate Evidence, Claims, or vocabulary.

The adapter follows the Responses API web-search tool and `web_search_call.action.sources` inclusion described in the [official Responses API reference](https://developers.openai.com/api/reference/cli/resources/responses/methods/create). The reference establishes request/response shape, not MEMENTO account access, freshness, or source quality.

## M11 — Family Admin

`IAdminAuthorizer` gates candidate listing and review annotations. `FamilyAdminReviewService` records the actor and annotation type, and only explicit family support/admin rejection changes candidate status. `WindowsAdministratorAuthorizer` binds authorization to the current Windows account and Administrators role; the fixed authorizer in tests remains a fixture. The WinUI shell exposes a candidate review dialog that can select every pending claim and shows each linked Evidence item, relationship, original expression, participant certainty, speaker-confirmation state, Source, and optional audio spans. An administrator can also play the latest finalized PCM WAV Source after its archived length, SHA-256, and WAV structure are verified; physical output-device verification remains pending.

Export, encrypted backup, and restore-verification controls use the same authorization boundary and record a minimal archive operation audit without storing paths or archive content.

## M12 — export and backup

`ArchiveExporter` writes table JSONL, an SQLite snapshot, optional source and derived-speech media, and a SHA-256 manifest. `ArchiveBackupProtector` encrypts and restores snapshots or complete export bundles with PBKDF2-derived AES-GCM keys, safe zip extraction, duplicate-entry rejection, reparse-point input rejection, and streaming manifest hash verification; wrong/corrupt passwords and unsafe archive paths fail.

The Family Admin shell also exposes `更新備份密碼`. It verifies the existing bundle's password and manifest before creating a new encrypted copy, preserves the original bundle, clears the password fields, and records a minimal audit event. This rotates a known password; family-owned key recovery and target-machine restore policy remain open.

## M13 — reliability/security foundations

`ArchiveHealthCheck` surfaces SQLite integrity, schema version, unfinished audio, due jobs, missing/tampered finalized source or derived speech assets, and semantic parity between canonical transcript/Evidence/Claim rows and the rebuildable search index, including Source/Session provenance and duplicate/unexpected rows. Windows Credential Manager readers reject malformed or oversized blobs before decoding, and malformed application-lock blobs fail closed instead of being treated as an absent lock; application-lock verifier parsing has the same bounded-input protection. The dependency vulnerability scan reports no vulnerable packages, and repository scans found no credentials or private media.

`ArchiveDeletionService` requires the Family Admin authorizer, removes a Source's dependent revisions, evidence, episodes, jobs, derived assets, and orphan entities, attempts to remove media, and records only a minimal authenticated deletion tombstone. It removes a Memory Claim only when no Evidence links remain; claims supported by another Source retain their remaining links, annotations, and search entry.

Deletion now also removes session-level provider metadata and derived speech when the deleted Source is the only session-level Source; when that scope is ambiguous, the records remain with an explicit finding rather than being deleted accidentally.

`ArchiveWithdrawalService` requires the same Family Admin boundary and records an attributed withdrawal annotation while retaining the historical Source and media. Pending/retryable jobs are terminally blocked, queued/future transcription and extraction re-check the withdrawn status, local lexical search omits withdrawn Source-linked records and claims, and ordinary exports produce a sanitized snapshot; an explicit `includeWithdrawn` export is available for controlled administrative handling.
