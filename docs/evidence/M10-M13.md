## M10 — current-information tools

`ISearchProvider` and `CurrentInformationService` return time-bound, URL-bearing, explicitly untrusted external information. `OpenAiWebSearchProvider` sends the Responses web-search tool with an explicit HTTPS domain allowlist and `store=false`, then discards citations outside that allowlist. The service has no path to mutate Evidence, Claims, or vocabulary.

The adapter follows the Responses API web-search tool and `web_search_call.action.sources` inclusion described in the [official Responses API reference](https://developers.openai.com/api/reference/cli/resources/responses/methods/create). The reference establishes request/response shape, not MEMENTO account access, freshness, or source quality.

## M11 — Family Admin

`IAdminAuthorizer` gates candidate listing and review annotations. `FamilyAdminReviewService` records the actor and annotation type, and only explicit family support/admin rejection changes candidate status. `WindowsAdministratorAuthorizer` binds authorization to the current Windows account and Administrators role; the fixed authorizer in tests remains a fixture. The WinUI shell exposes a simple candidate review dialog, pending supervised verification.

## M12 — export and backup

`ArchiveExporter` writes table JSONL, an SQLite snapshot, optional source and derived-speech media, and a SHA-256 manifest. `ArchiveBackupProtector` encrypts and restores snapshots or complete export bundles with PBKDF2-derived AES-GCM keys, safe zip extraction, and manifest hash verification; wrong/corrupt passwords and unsafe archive paths fail.

## M13 — reliability/security foundations

`ArchiveHealthCheck` surfaces SQLite integrity, schema version, unfinished audio, due jobs, and missing/tampered finalized source or derived speech assets. The dependency vulnerability scan reports no vulnerable packages, and repository scans found no credentials or private media.
