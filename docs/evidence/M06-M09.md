**Date:** 2026-09-13

## M06 — conversation persistence

`conversation_jobs` records durable transcription work with explicit state, attempt count, retry time, and error. `ConversationSessionWriter` creates sessions and turns, queues work only after a local Source exists, and transitions jobs without deleting audio. Durable processors re-check cloud consent and Source withdrawal before upload, and policy-blocked jobs stop without an infinite retry loop. Archive writes require an exact Source-to-Turn match when a Source is already turn-linked, so transcript revisions and queued jobs cannot silently drop that provenance. When a credential is available, the WinUI app starts the routed worker at launch so persisted work can resume after an ordinary restart; it also reports the due-job count when a credential is missing or the worker starts.

## M07 — memory extraction

`EvidenceRecord`, `MemoryClaim`, and `EvidenceClaimLink` are separate durable records. Evidence can carry audio spans and extraction provider/model metadata. `MemoryExtractionService` writes candidates with `ClaimStatus.Candidate`; an extraction provider cannot silently create a reviewed canonical claim. Both synchronous and asynchronous extraction boundaries re-check Source withdrawal before invoking a provider.

Model-supplied person IDs are checked against local `person_entities`; unknown IDs are discarded while the candidate statement remains reviewable, preventing an invalid model reference from poisoning a durable extraction job.

Evidence, candidate Claims, links, and search-index rows are committed in one SQLite transaction, so a failure while writing a later candidate rolls back the complete extraction batch.

`ArchiveSearchService` provides rebuildable local lexical search over transcript revisions, Evidence, and candidate Claims. FTS5 handles tokenized text, with a literal substring fallback for short Chinese queries; results exclude withdrawn Sources and deletion removes their index rows. The public `Rebuild()` operation can recreate the index from canonical tables after a local index repair or migration.

The WinUI shell exposes the service through a bounded search box and displays matching local records without adding a semantic or cloud retrieval dependency.

## M08 — provenance

`ProvenanceGraph.Validate` checks Source, transcript revision, Evidence, Claim, and link IDs plus allowed relationship names. An unconfirmed `AiInference` cannot be treated as a reviewed claim.

## M09 — vocabulary and entities

`PersonEntity`, `EntityAlias`, and `EvidenceEntityLink` provide additive identity context. Speaker-confirmed aliases retain the clarification event reference when available; old transcript and Source data remain immutable.

Entity resolution also provides review-only name/alias similarity suggestions with a conservative short-name rule. A suggestion is informational until a participant or Family Admin explicitly confirms it; no fuzzy suggestion creates an alias or Evidence link by itself. Multi-speaker diarization remains out of scope pending consent and attribution design.
